# DailyEnglish

App personal para seguir el plan diario de inglés (26 semanas). Funciona sin internet una vez instalada.

1. Sube todos estos archivos a la raíz de un repositorio de GitHub.
2. Settings > Pages > Deploy from a branch > main / (root).
3. Abre el enlace en Safari (iPhone) > Compartir > Agregar a inicio.
